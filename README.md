# 🎨 Algoritmica UI — Studio de Arte Generativa SaaS

Plataforma web interativa desenvolvida com foco em computação gráfica e manipulação de canvas em tempo real. O projeto combina conceitos de engenharia de front-end com design algorítmico e matemática aplicada.

## 🚀 Acesse o Projeto Online
👉 **[Clique aqui para acessar o SaaS rodando ao vivo](https://biellogin.github.io/algoritmica-ui/)**

---

## 🛠️ Tecnologias e Conceitos Aplicados
* **Front-end:** HTML5, CSS3, JavaScript (ES6+).
* **Motor Gráfico:** p5.js para renderização de canvas em tempo real.
* **Matemática Aplicada:** Utilização de vetores e algoritmos de *Perlin/Simplex Noise* para criar o fluxo orgânico das partículas.
* **UI/UX Design:** Painel de controle moderno em estilo SaaS (Dark Mode / Glassmorphism) com sliders dinâmicos e seletores de paleta de cores.
* **Exportação de Ativos:** Sistema de renderização para captura e download de imagens em alta definição (`.png`).
